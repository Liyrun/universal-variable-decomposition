# universal-variable-decomposition
是一套面向学术研究的通用文献变量拆解与研究设计结构化工作流。项目旨在将论文中的理论构念、变量定义、经验测度、数据来源、作用机制、识别策略及补充材料转化为统一、可追溯、可比较和可复用的结构化研究信息。

## Codex 技能

UVD-2.2 技能插件位于 [`plugins/universal-literature-variable-decomposition/`](plugins/universal-literature-variable-decomposition/)，包含技能说明和固定 Excel 模板。正式拆解应使用随包模板，并遵循技能文件中的 UVD-2.2 Schema。
